PUBLISH USING CARL'S OWN GITHUB ACCOUNT
1. Extract this ZIP file.
2. Sign in to https://github.com/ using Carl's account.
3. Create a NEW public repository, e.g. carl-francis-portfolio.
4. Choose "uploading an existing file". Upload index.html, style.css, and script.js directly to the repository root. Do not upload only the ZIP.
5. Commit the changes.
6. Open repository Settings > Pages.
7. Under Build and deployment, select "Deploy from a branch".
8. Select branch "main" and folder "/ (root)", then click Save.
9. Wait for deployment to finish. The expected URL format is:
   https://CARLS-GITHUB-USERNAME.github.io/carl-francis-portfolio/
   Replace CARLS-GITHUB-USERNAME with Carl's actual GitHub username. This is a format example, not a verified live URL.
10. If the site shows 404, check Settings > Pages and the Actions tab.

MAKE THE PROFILE PHOTO PERMANENT
The photo picker previews a photo temporarily in the browser. To keep a photo on the published site:
1. Put a chosen image in the same folder as index.html, named profile.jpg.
2. In index.html, replace the <div class="portrait" id="placeholder">...</div> and the <img id="profileImage"...> with:
   <img id="profileImage" src="profile.jpg" alt="Carl Francis D. Marcaida">
3. Upload profile.jpg with the other files and commit the change.
